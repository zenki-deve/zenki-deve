## About Me

Full-stack developer and automation engineer specializing in high-concurrency backend services, custom web applications, complex web scraping with anti-bot bypass, and Telegram ecosystems.

- **Backend & Microservices**: Scalable architectures using Python (FastAPI, Flask) and Go (Fiber, Gin) with Redis Streams and PostgreSQL.
- **Frontend & Web Apps**: Modern responsive interfaces using React 19, TypeScript, Tailwind CSS, and Vite.
- **Automation & Scraping**: High-load web scrapers with custom TLS fingerprinting (JA4), proxy pools, browser automation (Playwright, ZennoPoster, BAS), and Cloudflare / Akamai bypass.
- **Telegram Ecosystem**: Commercial bots, Telegram Mini Apps, payment and CRM webhook integrations.
- **Infrastructure**: Containerized deployments via Docker Compose, Nginx reverse proxies, Prometheus/Grafana monitoring, and Cloudflare Workers.
